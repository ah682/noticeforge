Get started

A working demo.
On your machine.

Install Python 3.12 and uv, then run: 

git clone https://github.com/ah682/noticeforge.git
cd noticeforge
make demo

Open http://127.0.0.1:8877. Five fictional notices are included. Uploaded documents and review history stay in your local database.

Before you use it

This website is a project overview. Uploads, review, BOM matching, and exports run in the local application.

The rules baseline recovered 18 of 19 exact part/date relationships on eight synthetic cases. Real supplier accuracy and engineer usefulness still need validation.

The app is designed for one local user and has no login. Optional models require setup and explicit review; they are off by default.
