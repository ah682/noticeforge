# COGD smartPCN implementation schemas

These two XSD files are **unmodified COGD material**, not schemas authored or
generated by NoticeForge. Their original copyright/author comments are retained.
They are outside the license applicable to NoticeForge's original source code.

The files were downloaded from the archive linked by the official
[smartPCN downloads page](https://smartpcn.org/downloads/) on 2026-10-13:
[smartPCN3.0_V3_08.zip](https://smartpcn.org/wp-content/uploads/2021/02/smartPCN3.0_V3_08.zip).
At that time the downloads page stated:

> All material is property of COGD and can be used, also partially, with reference to COGD.

Attribution: **COGD (Component Obsolescence Group Deutschland) e.V.**, smartPCN
working group. The body schema also credits H. Reger / DDM in its retained
header. NoticeForge relies on the publisher's stated permission to use these
implementation materials with this attribution. This permission does not cover
unrelated manufacturer notices or training data.

The body XSD header identifies `SmartPCN_3.08`, dated 2018-08-09. The specification
PDF linked by the publisher is titled
[Specification smartPCN 3.01 released 20180323](https://smartpcn.org/wp-content/uploads/2021/01/Specification-smartPCN-3.01-released-20180323.pdf).
That document describes the smartPCN 3.0 standard. Its document revision and the
XSD revision are different identifiers; NoticeForge pins the actual XSD revision.

`SOURCE.json` records the source URLs, permission, archive hash, and hashes of the
exact extracted files. The exporter uses `PCNbody_V3_08.xsd`; it does not use the
attachment schema because this release exports an XML body rather than the full
ZIP transport. `Attachment_V3_03.xsd` is retained from the same archive for
completeness, without claiming an implemented attachment export.

Reproduce the download without modifying the checked-in schemas:

```sh
curl -fL https://smartpcn.org/wp-content/uploads/2021/02/smartPCN3.0_V3_08.zip -o /tmp/smartPCN3.0_V3_08.zip
sha256sum /tmp/smartPCN3.0_V3_08.zip
```

Expected archive SHA-256:
`34068a3aaa8d03da656e52200a69926f7a945dcc365372c3fb8a37a9fc58fd3a`.
